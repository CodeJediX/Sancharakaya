Pitch / Demo Package

Executive summary

Sancharakaya (සංචාරකයා) is a conversational, AI-powered travel companion designed specifically for individual tourists exploring Sri Lanka. It combines an LLM-driven itinerary planner, a 24/7 multilingual assistant, a predictive recommendation engine, a scam and safety alert system, and a sustainable-tourism matching tool into a single web-based platform.

Problem

  • Fragmented trip-planning information
  • Overcharging and scams
  • Language and cultural gaps
  • Generic recommendations not tailored to Sri Lanka
  • Overcrowding at major sites
  • Safety uncertainty for independent travelers

Solution modules

  • AI Itinerary Planner
  • 24/7 Multilingual Virtual Assistant
  • Predictive Recommendation Engine
  • Fair-Price Guide
  • Safety & Scam-Alert System
  • Sustainable Tourism Matching

Technology

  • LLM core via Anthropic Claude API
  • Retrieval-Augmented Generation using a Sri Lanka knowledge base
  • Predictive analytics for seasonality and crowd flow
  • NLP for multilingual chat and intent detection

Business model

  • Freemium subscription
  • Booking commission
  • B2B / DMO licensing
  • Verified partner listings

Why this matters for SLTDA

  • Enhances visitor experience
  • Improves operational efficiency
  • Supports sustainability
  • Promotes digital transformation
  • Generates employment opportunities

Secure API architecture

The browser never receives an Anthropic API key. When enabled, requests go to /api/chat, where a server-side proxy reads ANTHROPIC_API_KEY from environment variables. Without that proxy, Sancharakaya safely remains in offline mode.
